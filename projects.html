AI-Powered Disaster Warning System

AI / MACHINE LEARNING / LLM

Built with teammate Summaya Shaikh, this project turns raw hazard data (flood, earthquake, landslide, drought) into structured, actionable warnings for Pakistan. My focus was prompt engineering and LLM API integration — designing prompts that resist hallucination and produce consistent, trustworthy output every time.

Python LLaMA 3.1 Groq API HTML JSON
GitHub

Technical Highlights

Model: LLaMA 3.1-8b-instant via the Groq API

Output format: Structured JSON — severity_level, headline, message, recommended_action, region, disaster_type, risk_score

Reliability controls: Temperature set to 0.3 to reduce randomness, plus explicit anti-fabrication constraints so the model never invents data it wasn't given

Stack: Python backend, HTML frontend
